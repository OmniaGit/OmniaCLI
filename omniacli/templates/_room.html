One for every dialog that makes a backup to restore (Backup, Copy production to test, Copy from link): include it once in the page, then const room = omniaRoom(holder); room.estimate(data); // /api/servers///backup/estimate of the instance backed up, // or {error} room.room(data, what); // /api/servers///restore/room of the instance that // receives it, or {error}; null: no restore to check; // what: "the restore into srv/test" room.reset(withRoom); // reading again (withRoom false: no restore to check) room.update({files, ticked, zip}); // files: the filestore is in the backup and restored; ticked: the bytes // of the binary columns left out; zip: the zip is written on this machine The sizes are estimates from the sizes on disk, on the high side: the dump of the database is its size on disk plus once more the binary rows kept (pg_dump writes them in hex), the zip is not counted compressed. Per disk it adds up what the restore writes there (the zip, the backup unpacked, PostgreSQL's data, the filestore) against its free room plus what the restore drops there first (the old database and filestore). -#}
